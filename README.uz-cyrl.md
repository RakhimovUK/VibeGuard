# VibeGuard

[O'zbekcha (lotin)](README.md) · Ўзбекча (кирилл) · [Русский](README.ru.md) · [English](README.en.md)

Вайбкодинг билан ёзилган лойиҳаларни (Telegram бот, Mini App, сайт, APK) хавфсизлик ва хатоларга текширадиган Claude Code плагини. **Red Team** режимида 13 хил ҳужумчи кўзи билан кодни ўқийди, заиф жойларни топади, тузатиш йўлини кўрсатади ва тасдиқ билан тузатади.

> Фақат ўзингизга тегишли ёки ёзма рухсат олинган лойиҳаларда ишлатинг. Кафолат йўқ. MIT лицензия.

## Ўрнатиш (Claude Code)

```
/plugin marketplace add <github-фойдаланувчи>/vibeguard
/plugin install vibeguard@vibeguard
```

## Буйруқлар

| Буйруқ | Нима қилади |
|---|---|
| `/vibeguard:redteam [қисм]` | Тўлиқ ҳужум: скриптлар, ҳужумчилар, скептик, занжирлар, ҳисобот |
| `/vibeguard:quick` | Тезкор: сирлар ва критик хатолар |
| `/vibeguard:ship` | Чиқаришдан олдин: фақат охирги ўзгаришлар, «тайёр / тайёр эмас» |
| `/vibeguard:fix VG-001` | Тасдиқ билан тузатиш: тест, алоҳида branch, қайта ҳужум |
| `/vibeguard:guard on` | Қўриқчи: кодга сир ёзилса тўхтатади |
| `/vibeguard:rules` | Топилган хатолардан `CLAUDE.md` га лойиҳа қоидалари |
| `/vibeguard:incident` | Сизиш ёки бузилишда қадамма-қадам йўриқнома |
| `/vibeguard:lang uz-cyrl` | Тил: `uz`, `uz-cyrl`, `ru`, `en` |

Биринчи ишга тушишда рухсат тасдиғи ва тил сўралади.

## Ҳисоботда нима бор

- Хавф бали (0-100) ва ҳукм: чиқаришга тайёр / тайёр эмас.
- **Бугун 3 та иш:** энг муҳим учта тузатиш.
- **Вақт бюджети:** ҳужумчи 10 дақиқада, 1 кунда, 1 ҳафтада нимага етади.
- **Ҳужум занжирлари:** майда хатолар бирга қандай катта зарар беради ва қайси битта тузатиш занжирни узади.
- Ҳар бир топилма (`VG-001`): қаерда, далил, ҳужумчи даражаси, ҳужум йўли, тузатиш, тузатилмаса нима бўлади, Claude Code учун тайёр промпт.
- «Ўзингиз қиласиз» рўйхати (масалан, сизган токенни алмаштириш).
- Қизил ва кўк ҳисоб, қайта ҳужум натижаси. HTML кўриниши ҳам ясалади.

## Ҳужумчилар

outsider (аноним), user (ёмон ниятли фойдаланувчи), token (сизган сирни қўлга киритган), fraudster (тўлов ва мантиқ фирибгари), cost (харажат ҳужумчиси), supply (боғлиқликлар ва CI), deploy (инфратузилма), takeover (аккаунт ўғриси), insider (собиқ админ), scraper (маълумот йиғувчи), phisher (сохталаштирувчи), apk (иловани очиб ўқийдиган), ai (prompt injection).

Скептик агент ҳар бир топилмани қайта текширади. Исботсиз топилма ҳисоботга кирмайди.

## Хавфсизлик чегаралари

- Сукут бўйича фақат код ўқилади. Жонли синов фақат localhost ёки сиз кўрсатган тест муҳитида.
- Тайёр эксплойт ёзилмайди.
- Код фақат тасдиқдан кейин, алоҳида branch'да ўзгаради. Push, merge ва deploy сизда қолади.
- Тоза ҳисобот хавфсизлик кафолати эмас.

## Бошқа воситалар ва CI

- Cursor, Codex ва шунга ўхшашлар: `adapters/AGENTS.md`.
- GitHub'да ҳар PR'ни текшириш: `adapters/github-action/vibeguard.yml` (фақат скриптлар, AI'сиз).
- Қўриқчи режими `python3` талаб қилади.
