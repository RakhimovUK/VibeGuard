# VibeGuard

[O'zbekcha (lotin)](README.md) · [Ўзбекча (кирилл)](README.uz-cyrl.md) · Русский · [English](README.en.md)

Плагин для Claude Code, который проверяет проекты, написанные вайбкодингом (Telegram-боты, Mini App, сайты, APK), на уязвимости и ошибки. В режиме **Red Team** он читает код глазами 13 разных атакующих, находит слабые места, объясняет, как их исправить, и исправляет с вашего подтверждения.

> Используйте только на своих проектах или там, где есть письменное разрешение. Без гарантий. Лицензия MIT.

## Установка (Claude Code)

```
/plugin marketplace add <github-пользователь>/vibeguard
/plugin install vibeguard@vibeguard
```

## Команды

| Команда | Что делает |
|---|---|
| `/vibeguard:redteam [часть]` | Полная атака: скрипты, атакующие, скептик, цепочки, отчёт |
| `/vibeguard:quick` | Быстро: секреты и критические ошибки |
| `/vibeguard:ship` | Перед выпуском: только последние изменения, «готов / не готов» |
| `/vibeguard:fix VG-001` | Исправление с подтверждением: тест, отдельная ветка, повторная атака |
| `/vibeguard:guard on` | Страж: не даёт записать секрет в код |
| `/vibeguard:rules` | Правила проекта в `CLAUDE.md` по найденным ошибкам |
| `/vibeguard:incident` | Пошаговая инструкция при утечке или взломе |
| `/vibeguard:lang ru` | Язык: `uz`, `uz-cyrl`, `ru`, `en` |

При первом запуске спрашивается подтверждение разрешения и язык.

## Что в отчёте

- Балл риска (0-100) и вердикт: готов к выпуску / не готов.
- **Три дела на сегодня:** самые важные исправления.
- **Бюджет времени:** чего атакующий добьётся за 10 минут, 1 день, 1 неделю.
- **Цепочки атаки:** как мелкие ошибки складываются и какое одно исправление рвёт цепочку.
- Каждая находка (`VG-001`): где, доказательство, уровень атакующего, путь атаки, исправление, что будет, если не исправить, готовый промпт для Claude Code.
- Список «сделайте сами» (например, заменить утёкший токен).
- Счёт красных и синих, результат повторной атаки. Создаётся и HTML-версия.

## Атакующие

outsider (анонимный), user (злонамеренный пользователь), token (получил утёкший секрет), fraudster (мошенничество с оплатой и логикой), cost (накручивает ваш счёт), supply (зависимости и CI), deploy (инфраструктура), takeover (кража аккаунта), insider (бывший админ), scraper (массовый сбор данных), phisher (подделка), apk (разбор приложения), ai (prompt injection).

Агент-скептик перепроверяет каждую находку. Находки без доказательств отбрасываются.

## Границы безопасности

- По умолчанию только чтение кода. Живые проверки только на localhost или в указанной вами тестовой среде.
- Готовые эксплойты не пишутся.
- Код меняется только после подтверждения, в отдельной ветке. Push, merge и деплой остаются за вами.
- Чистый отчёт не гарантирует безопасность.

## Другие инструменты и CI

- Cursor, Codex и подобные: `adapters/AGENTS.md`.
- Проверка каждого PR на GitHub: `adapters/github-action/vibeguard.yml` (только скрипты, без ИИ).
- Режиму стража нужен `python3`.
